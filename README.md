# Bookshelf

ASP.NET Core MVC (.NET 8) with Entity Framework Core and SQL Server LocalDB.
Uses the same six manga books as the original project.

## Run in Visual Studio on Windows

1. Extract this ZIP into a new folder. Open Bookshelf.sln.
2. Install the ASP.NET and web development workload, .NET 8 SDK, and SQL Server Express LocalDB through Visual Studio Installer if needed.
3. Restore NuGet packages (right-click the solution > Restore NuGet Packages).
4. Open Tools > NuGet Package Manager > Package Manager Console. Set the default project to Bookshelf and run:

   Update-Database

5. Press Ctrl+F5 and open http://localhost:5124/books.

The connection string is in appsettings.json. It creates a separate database named Bookshelf on (localdb)\MSSQLLocalDB.
Both migrations are already included: InitialCreate creates and seeds the table;
AddRating adds the optional nullable Rating column. Do not run Add-Migration
with those names again. Update-Database applies both in order.
To inspect just the first stage, run Update-Database InitialCreate before the
first launch, view dbo.Books, then run Update-Database to add Rating.
The final application requires both migrations before it runs.

## Assignment changes

- EF Core SQL Server and Tools package references.
- Data/AppDbContext.cs, DbSet<Book>, six HasData seed records (IDs 1–6).
- Database context registration in Program.cs.
- InitialCreate, AddRating and the current model snapshot in Migrations.
- BooksController uses the database for listing, details, read/unread and adding.
- Details uses ViewBag.LastId from the database count.
- GET /books/new and POST /books/add, with server validation and anti-forgery token.
- Required title/author and page range 1–5000. No ID input; SQL Server assigns it.
- Optional rating 1–5 displayed on cards and details; blank ratings are allowed.
- Read and unread changes call SaveChanges before redirecting; flash messages use TempData.

The mark links use GET to preserve the classroom exercise. For a production app,
use POST with anti-forgery protection for all state changes.
